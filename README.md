# Claire Louise Fitness

Static website for Claire Louise Fitness.

## Preview / deployment

- Deploy the repository directly to Vercel as a static site.
- No build command is required.
- Output directory can be left blank / default.

## Before the production launch

Add the final domain to the canonical and Open Graph metadata, connect the enquiry form to Claire's real email/form endpoint, confirm Claire's exact town/service area, then create sitemap.xml and add the site to Google Search Console.
